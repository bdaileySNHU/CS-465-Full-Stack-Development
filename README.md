For this project the front end user facing website uses Express with Handlebars templates. The authenticated admin panel uses an Angular single page application to allow the admin to see the editing features of the website. For the backend I used MongoDB for the database because it stores data in JSON format. This allows me to easily pass the information stored like trips and users records without having to transform the data into another format. It also allows for a more flexible data schema.

JSON is a text-based data format not a full programming language. Since all the technologies in the stack interact with JSON I am able to hand the data back and forth between the front end and the back end without any issues. I started with hardcoded data for the trips that was stored in the html itself. I then later used a getTrips() method to retrieve the data from the database and then transform it into html to display on the page. I was able to write a TripCardComponent that was used to display the trip data no matter the amount of trips we displayed.

An API endpoint is a way for the front end to communicate with the back end. In this project I used a get /api/trips endpoint to retrieve the trips from the database. I was able to test these using the Postman application before integrating them into the front end. I used JWT authentication to encrypt the user’s login information so it never leaves the front end unencrypted. 

Over this course I’ve learned a lot about full stack development. About how the pieces of the stack fit together and how to use them. I think this is a very in demand skill and help makes me a more well rounded developer by not being too specialized in one area of the stack.
